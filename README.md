SENTIMENT ANALYSIS APLIKASI PLUANG

Deskripsi Project
Project ini bertujuan untuk menganalisis sentimen pengguna terhadap aplikasi Pluang berdasarkan ulasan yang diberikan. Analisis dilakukan untuk memahami persepsi pengguna serta mengidentifikasi kecenderungan sentimen terhadap layanan aplikasi.

Hasil analisis menunjukkan bahwa mayoritas ulasan pengguna berada pada kategori positif, yang mengindikasikan tingkat kepuasan pengguna yang cukup tinggi.

Tujuan
- Mengklasifikasikan sentimen ulasan pengguna (positif dan negatif)
- Mengetahui distribusi sentimen pengguna terhadap aplikasi Pluang
- Membandingkan performa beberapa model machine learning dalam klasifikasi sentimen


Hasil dan Insight
- Sentimen pengguna didominasi oleh sentimen positif
- Model Logistic Regression memberikan performa terbaik dibandingkan model lainnya
- Model ini mampu menghasilkan prediksi yang lebih stabil dan akurat dalam klasifikasi sentimen

Catatan
Project ini dibuat sebagai bagian dari pengembangan kemampuan di bidang Data Analysis dan Machine Learning, khususnya dalam Natural Language Processing (NLP).
